# SpaceThon — Sistema de Reciclagem Espacial 🚀

## 📝 Descrição do Projeto

O **SpaceThon** é um sistema desenvolvido como parte da **Global Solution 2026 - FIAP**. O projeto visa combater o crescente problema do lixo espacial na órbita terrestre. 

Nossa solução propõe o uso de drones autônomos equipados com IA e braços robóticos, capazes de coletar detritos espaciais e trazê-los em segurança para a Terra através de um sistema de reentrada controlada. Todo o material recuperado (alumínio, titânio, cobre, etc.) é supervisionado, para identificação de riscos, logo após, é reciclado em uma base recicladora e redirecionado ao mercado por meio do nosso **Dashboard B2B**.

### 🌍 Impacto e ODS
O projeto SpaceThon atende diretamente aos Objetivos de Desenvolvimento Sustentável (ODS) da ONU:
- **ODS 8:** Trabalho Decente e Crescimento Econômico
- **ODS 9:** Indústria, Inovação e Infraestrutura
- **ODS 12:** Consumo e Produção Responsáveis
- **ODS 13:** Ação Contra a Mudança Global do Clima
